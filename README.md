# TuneScript
Web application for transcribing piano MP3 recording into PDF sheet music

## Installation
1. Clone the repository

```bash
git clone https://github.com/mj300405/TuneScript.git
```

2. Go to the project devtools directory

```bash
cd TuneScript/devtools
```

3. Run docker-compose (you need to have docker installed)

```bash
docker-compose up --build
```

4. Open the project in your browser
```bash
localhost:3000
```
